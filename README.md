# ERP Académico con Scrum

Proyecto académico para aplicar Scrum construyendo módulos de un ERP con trazabilidad entre requisitos, diseño, arquitectura, código y pruebas.

## Módulos
- Inventario
- Clientes / CRM

## Herramientas
- Figma (diseño)
- PlantUML (diagramas)
- GitHub (control de versiones)
