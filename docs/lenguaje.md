# ADR-001 Lenguaje de Programación

## Contexto
El proyecto requiere un lenguaje orientado a objetos, ampliamente utilizado en entornos empresariales, con buen soporte para arquitecturas en capas y desarrollo de aplicaciones tipo ERP.

Además, el docente ha indicado que el proyecto debe desarrollarse utilizando C#.

## Decisión
Se utilizará **C#** como lenguaje principal de desarrollo del sistema ERP.

## Consecuencias
- Integración natural con .NET.
- Buen soporte para arquitectura en capas.
- Amplia documentación y ejemplos.
- Curva de aprendizaje moderada para el equipo.
