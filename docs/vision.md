# Visión del ERP

Para una cadena de cafeterías que necesita gestionar de forma integrada sus operaciones diarias, nuestro sistema ERP proporciona una plataforma centralizada para administrar inventario y clientes, permitiendo un control confiable de la información, reducción de errores manuales y mejor toma de decisiones, a diferencia de soluciones basadas en hojas de cálculo o sistemas aislados.

El sistema se desarrollará de manera incremental utilizando el marco de trabajo Scrum, garantizando entregas funcionales frecuentes y trazabilidad entre requisitos, diseño, arquitectura, código y pruebas.

---

## Visión del Módulo de Inventario

Para responsables de almacén y encargados de sucursal que necesitan conocer y mantener actualizado el stock de insumos y productos, el módulo de Inventario permite registrar productos, entradas y salidas de stock, y consultar existencias en tiempo real, asegurando información confiable para evitar quiebres o desperdicios.

---

## Visión del Módulo de Clientes (CRM)

Para el personal de atención y el área comercial de la cadena de cafeterías, el módulo CRM permite registrar, actualizar y consultar datos de clientes, así como revisar su historial de interacciones, facilitando una mejor gestión de relaciones y fidelización.

---

## Alcance del Proyecto

Incluye:
- Registro y consulta básica de inventario.
- Registro de entradas y salidas de stock.
- Registro y consulta básica de clientes.
- Interfaces web simples.
- Persistencia de datos.

No incluye:
- Facturación electrónica real.
- Pagos en línea.
- Integraciones con sistemas externos reales.

---

## Objetivo Académico

Aplicar de forma práctica Scrum y buenas prácticas de ingeniería de software, integrando requisitos, diseño UX, arquitectura, desarrollo, pruebas y control de versiones en un proyecto funcional orientado a una cadena de cafeterías.
