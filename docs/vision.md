# Visión del ERP

Para pequeñas y medianas empresas que necesitan gestionar de forma integrada sus operaciones diarias, nuestro sistema ERP proporciona una plataforma centralizada para administrar inventario y clientes, permitiendo un control confiable de la información, reducción de errores manuales y mejor toma de decisiones, a diferencia de soluciones basadas en hojas de cálculo o sistemas aislados.

El sistema se desarrollará de manera incremental utilizando el marco de trabajo Scrum, garantizando entregas funcionales frecuentes y trazabilidad entre requisitos, diseño, arquitectura, código y pruebas.

---

## Visión del Módulo de Inventario

Para responsables de almacén y operarios que necesitan conocer y mantener actualizado el stock de productos, el módulo de Inventario permite registrar productos, entradas y salidas de stock, y consultar existencias en tiempo real, asegurando información confiable para evitar quiebres o sobrestock.

---

## Visión del Módulo de Clientes (CRM)

Para personal del área comercial que requiere administrar información de clientes, el módulo CRM permite registrar, actualizar y consultar datos de clientes, así como revisar su historial, facilitando una mejor gestión de relaciones y soporte a los procesos de venta.

---

## Alcance del Proyecto

Incluye:
- Registro y consulta básica de inventario.
- Registro y consulta básica de clientes.
- Interfaces web simples.
- Persistencia de datos.

No incluye:
- Facturación electrónica real.
- Integraciones con sistemas externos reales.
- Procesos contables avanzados.

---

## Objetivo Académico

Aplicar de forma práctica Scrum y buenas prácticas de ingeniería de software, integrando requisitos, diseño UX, arquitectura, desarrollo, pruebas y control de versiones en un proyecto funcional.
